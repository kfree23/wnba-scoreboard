# WNBA Live Scoreboard
 
A live scoreboard tracking WNBA games in real time. Scores update automatically every 30 seconds, and you can filter games by team name instantly.
 
## Features
 
- Live scores with automatic 30-second polling
- Real-time team search and filtering
- Game status badges — Live, Final, Upcoming
- Responsive card grid for all screen sizes
- Full loading, error, and empty state handling
## Tech Stack
 
- React
- TypeScript
- CSS
- ESPN unofficial API (no key required)
